# Chess pieces

Twelve SVGs (`wK` ... `bP`). Kings to knights are the Unicode chess glyphs (U+265A to U+265E), filled and
stroked per side; pawns are drawn shapes, because Windows draws its own outlined pawn for U+265F whatever the fill. Our own files, no third-party licence. The glyph shape comes from the system
font at render time (Segoe UI Symbol on Windows), so swap these for a drawn set if a short needs
a fixed look on every machine.
