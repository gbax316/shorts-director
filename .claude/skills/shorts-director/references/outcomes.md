# Outcomes, evals and loops

What this skill has to produce, how to tell whether it is producing it, and how it improves. The improve mode scores every run against this file. Targets were first guesses on 1 November 2026; the "measured so far" column is what real runs set, and it moves as `RUNS.md` grows.

## Outcomes

| Outcome | Measured as | Target | Measured so far | Stops it |
|---|---|---|---|---|
| The owner takes the first cut | revision rounds to approval, each labelled direction, taste or fault | 0 or 1 | episode 2: about 3 (pidgin takes twice, the customers redrawn, eyebrow re-roll); documentary 1: about 3 (audience changed, Qodeup focus, dates moved to a card) | 3 or more on a run with a settled brief |
| The words are visible | beats with an idea on screen the voice does not say | every line | episode 2 and documentary 1: every line | a line with nothing to see |
| No visible faults | faults the owner finds before the checks do | 0 at hand-over | episodes 1 and 2: 2 found late in episode 1, none in episode 2's cut; documentary 1: none | any fault the owner finds first |
| Viewers stay | still watching at 3 s, average view, completion | set by the first posted runs | none posted yet | |
| Viewers act | clicks on the tagged link per video | set by the first posted runs | none posted yet | |
| Range | divergent formats shipped | 2 by v1, 3 by v1.1 | 2 (skit, mini documentary) | a version that only does one format |
| Cost is visible | every spend stated before it runs and totalled after | every run | every run so far | a spend the owner learns about afterwards |

## Evals

Before pixels, per short: three premises judged as the buyer; the fact gate on anything stated as true; the animatic on the real voice timeline; when available, a model from a different family reads the script and watches the animatic cold.

After pixels, per short: the frame-jump scan on every clip and on the whole cut; identity against the references; mouths against who is speaking; captions against word times; the style scan on every spoken and on-screen word; loudness against the mastering target; the owner's eye and ear last.

Across the system: revision rounds per short and what caused them, faults the owner found first, cost per finished short, and audience numbers per format and series once they exist.

## Loops

| Trigger | Where the lesson lands | Who approves | Way back |
|---|---|---|---|
| A fault fixed in one video | that video's beats and notes | the owner's approval of the cut | git |
| The same fault twice, a proven technique, or an owner's correction about how the skill works | `LESSONS.md`, then the skill in general terms | the owner, on reading the diff | revert that one commit |
| Audience numbers after posting | the format's grammar and the series bible | the owner | the old grammar stays in history |
| A bakeoff winner | the default for that job in `director.config.json` | the owner, by eye | the config keeps the losers and the date |
